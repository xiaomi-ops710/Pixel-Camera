# 無音カメラ (SilentCam)

iPad(第10世代 / A14)向け・シャッター音ゼロの高画質カメラPWA。図書館などでの資料撮影用です。
Material 3 スタイル + Material Symbols アイコン / iPadのカメラに近い配置 / ビルド不要の静的ファイルのみ。

## GitHub Pages へのデプロイ

1. GitHubで新規リポジトリを作成し、このフォルダの中身をそのまま `main` ブランチにpush(`.github` と `.nojekyll` も含める)
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. push すると自動デプロイ → `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開
   (ワークフローを使わない場合は Source を「Deploy from a branch → main / (root)」でも可)

すべて相対パスなので、サブパス(`/<リポジトリ名>/`)でもそのまま動きます。カメラはHTTPS必須ですが、GitHub PagesはHTTPSなので問題ありません。

## iPadへのインストール

1. Safariで公開URLを開く
2. 共有ボタン → **ホーム画面に追加**
3. ホーム画面のアイコンから起動(全画面・オフライン対応)。初回にカメラ許可を「許可」

> ホーム画面に追加したPWAは、Safariのタブと違い保存データが7日未使用で消去される対象になりません。

## 機能

| 機能 | 内容 |
|---|---|
| 完全無音 | OSの撮影APIを使わず、ライブ映像から原寸フレームを直接書き出し。音・振動のAPIは未使用 |
| 写真 / スクエア / ビデオ | 右側のモード切替(iPadのカメラと同じ並び) |
| 画質 | 最大 4032×3024 を要求(端末が対応する最大)。JPEG品質 80〜100%、またはPNG(無劣化) |
| ズーム | ピンチ / 左の「1×」ボタン(プリセット+スライダー)。ハードウェアズーム対応ならそれを使用、非対応は中央・ドラッグ移動できるデジタルズーム |
| ズーム時の画質 | 既定は「切り出し」=拡大補間なしで元の画素のまま保存。設定で「元サイズに拡大」も選択可 |
| 連写 | シャッター長押し、または連写モードON→タップで開始/停止。間隔・最大枚数は設定可。保存は裏でキューイング |
| ビデオ | 最大4K/60fps、H.264(mp4)。音声は既定OFF(完全無音動画)。録画中も静止画を撮影可 |
| ギャラリー | iPadOS「写真」に近い配置。日付ごとのグループ表示 / 上部は戻る・選択・その他、下部はタブ(すべての写真・日)/ 選択時は下部に共有・★・ZIP・PDF・削除 / 長押しで選択開始 |
| ビューア | 上部のカプセル(共有・★ / 日時 / 編集・情報・削除・その他)、下部のフィルムストリップ、タップでUIを隠す、ピンチ拡大(最大12倍で文字の確認)、スワイプ送り、★1〜5の評価、非表示、スライドショー、情報パネル |
| 書き出し | 共有シート経由で「画像を保存」(写真App)や「ファイルに保存」。ダウンロードも可 |
| セルフタイマー | 3秒 / 10秒 |
| 補助表示 | グリッド、水準器(机に置いて真上から撮る時は十字、立てた時は水平線)、タップでピント指示 |
| 資料補正コピー | 元画像はそのまま、自動レベル補正または白黒資料化した版を別ファイル(`_enh`)で同時保存 |
| ブレ抑制シャッター | 端末の揺れが収まるのを待ってから撮影(最大1.5秒) |
| AE/AFロック | 画面長押しでロック/解除(カメラが対応している場合) |
| 露出補正 | ズームパネル内のスライダー(カメラが対応している場合) |
| お気に入り / ZIP書き出し | ギャラリーで★付け・絞り込み、複数選択して無圧縮ZIPにまとめて共有 |
| ファイル名の接頭辞 | 「日本史B_」など本ごとの名前を付けて整理 |
| 画面を暗くする | 暗い閲覧室向けに画面の光を弱・強で抑える(上部の☀︎ボタン) |
| 外部キー / リモコン | Space・Enter・→・PageDownでシャッター(ページめくり用Bluetoothリモコン可)、+/−でズーム |
| アニメーション | リップル、シートの遷移、撮影時にサムネへ飛ぶ演出など。設定でOFF可(OSの「視差効果を減らす」にも追従) |
| スキャン補正 | ギャラリーのビューアで📄ボタン。資料の枠を自動検出して台形補正(4隅はドラッグで調整)。元の解像度のまま展開し、新しいファイル(`_scan`)として保存 |
| 補正フィルタ | そのまま / 自動レベル / 影除去(紙のムラ・影を均して白く)/ グレー / 白黒。「仕上がり確認」で保存前にプレビュー |
| 見開き分割 | 本の見開きを中央線で左右2ページに分け、それぞれ台形補正して保存(`_scanL` / `_scanR`) |
| PDF書き出し | ギャラリーで複数選択→PDF。撮影順がページ順。JPEGは再圧縮せずそのまま埋め込み(画質劣化なし) |
| 連番ファイル名 | 設定でON。IMG_0001, 0002… と保存。「次の番号」で本ごとにリセット |
| ピント確認 | 上部ボタン。ピントが合っている輪郭を黄色で表示(ピーキング) |
| 直前の1枚を削除 | 撮影直後の5秒間、画面左下に表示。撮り損ねをその場で消せる |
| ギャラリー便利機能 | 「その他」メニューで並び替え(新しい順・古い順)・絞り込み(すべて / 写真 / ビデオ / お気に入り / 非表示)・選択 |
| 撮影オプション | 上部の「…」ボタン。下記の撮影補助をまとめて設定 |
| アスペクト比 | フル / 3:2 / 16:9 / 1:1 / A4(写真)。撮影範囲をその比率で切り出し、プレビューにも反映 |
| 自動撮影: ページ自動 | シャッターで開始。ページをめくって動きが止まると自動で撮影。同じ内容の重複は撮らない。感度(低/中/高)を選択 |
| 自動撮影: インターバル | 2/5/10/30秒の間隔で自動撮影。枚数指定(10/30/100/無制限)で自動停止。画面上部のチップで停止 |
| ヒストグラム | 明るさの分布を画面右下に表示。黒つぶれ・白飛びは色付きのバーで知らせる |
| 白飛び警告(ゼブラ) | 白飛びしている部分に斜線を表示。紙の白飛び確認に |
| カメラ調整 | 端末が対応する項目のみ表示(露出・ピントの自動/手動、露出時間、ISO、ホワイトバランス等)。「すべて自動に戻す」あり |
| ダブルタップで撮影 | 設定でON。プレビューを2回タップでシャッター |
| ビデオの一時停止 | 録画中に一時停止/再開。停止中の時間は録画時間に含めない |
| 撮影と同時にスキャン補正 | 設定でON。撮影のたびに枠を検出して台形補正した版を `_scan` で同時保存(仕上げフィルタも選択可) |
| その他 | 画面スリープ防止、縦横どちらでも使用可、オフライン動作 |

## スキャン補正のコツ
- 資料は暗い机の上に置くと、枠の自動検出が安定します(白い机だと枠を検出できないことがあります。その時は4隅をドラッグ)。
- 影除去・白黒は文字中心の資料向けです。写真やカラー図版が多いページは「そのまま」か「自動レベル」を選んでください。
- 補正は元の画像を変更しません(「元の画像を置き換え」をONにした時だけ入れ替えます)。

## 画質について(正直なところ)

- 写真は「カメラ映像の1フレーム」を書き出す方式です(Safariには、ネイティブのカメラAppのような静止画専用撮影APIがありません)。そのため HEIC / ProRAW / Smart HDR などは使えません。
- 解像度は端末とiPadOSの対応次第です。画面上部のチップに実際の解像度(例 `3840×2160`)が表示されるので確認してください。
- 画質を最優先するなら: 写真解像度=最大 / JPEG品質=97〜100 / ズームはなるべく使わず近づいて撮る。
- 資料(紙面)は真上から撮り、水準器の十字を合わせるとパースの歪みが減ります。

## ファイル構成

```
index.html / styles.css / app.js   アプリ本体
gallery.js                         ギャラリー・ビューア(iPadOS風)・共有・ZIP
scan.js                            スキャン補正・PDF・ピーキング
capture.js                         撮影オプション・自動撮影・ヒストグラム・カメラ調整
sw.js / manifest.webmanifest       PWA(オフライン・インストール)
icons/                             アプリアイコン + Material Symbols(使用分のみ抽出した静的フォント。Safari互換のためwoff+ttf、塗り/線の2種)
icons.css                          アイコン名→文字コード対応
.github/workflows/pages.yml        GitHub Pages 自動デプロイ
```

更新時は `sw.js` の `VERSION`(現在 `v15`)と `app.js` の `APP_VERSION` を上げてください。キャッシュ名(`silentcam-shell-v15`)が変わり、古いキャッシュは自動で削除されます。
